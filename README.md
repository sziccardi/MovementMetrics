
# Bilateral Motion Analysis Toolkit (BMAT)

A web-app for analyzing bilateral arm movement using time-series motion data captured by a single straight-on camera. Designed for researchers, therapists, clinicians, and fitness professionals, this tool enables easy visualization, comparison, and assessment of arm motion patterns. Built using **Streamlit**.

Developed by the [Applied Motion Lab]() and the [Neural Rehabilitation Across the Lifespan Lab]() at the University of Minnesota.

---

## Features

- **Custom Data Visualization**: Upload movement videos or pre-processed data to visualize quantitative motion information of relevent joints.
- **Linked Views**: Dive deeper into specific data points using the selection tool and see where those poitns appear in all other visualizations.
- **Metrics Calculation**: Compute symmetry indices, range of motion, peak velocity, and more.
- **Export Results**: Save processed movement for future analysis.
- **Web-Based**: No installation required beyond Python, and runs in your browser.

---

## Use Cases

- **Rehabilitation Tracking**: Monitor recovery progress in stroke, Cerebral Palsy, or injury patients.
- **Athletic Performance Analysis**: Identify movement imbalances in training.
- **Biomechanics Research**: Study motion symmetry and joint performance for future diagnostic purposes.

## Getting Started

### Prerequisites

Ensure you have Python 3.8 or later and install required packages.

```bash
pip install -r requirements.txt
````

> If `requirements.txt` is not available, the main dependencies are:
>
> ```
> streamlit
> pandas
> matplotlib
> numpy
> plotly
> ```

### ▶️ Run the App

```bash
streamlit run main.py
```

### Uploading a New Video
1. Use the **file uploader** in the app to load your video in **Mp4 or MOV format** . Video file must be <200mb in size.
2. Select 'run'
3. Wait for the algorithm to extract the pose data (this could take a significant amount of time depending on the length of the video).

### Uploading a Previously Processed Video
1. Use the **file uploader** in the app to load your video in **Mp4 or MOV format**. Video file must be <200mb in size.
2. Use the **file uploader** in the app to load the previously generated motion data in **CSV format**.
3. Make sure it was generated by BMAT and contains at least the following columns:

   * `time`
   * `frame`
   * `keypoint_name`
   * `x`,	`y`,	`z`
   
4. Select 'run'

### Using the App

1. Select which keypoints (AKA: joints) you want to visualize. You can change this whenever you wish.
2. Investigate the different widgets for:
  * Video analysis
  * Position point cloud plots
  * Position over time plots
  * Summary statistics
3. Use sidebar settings to adjust display options (e.g., time window, plot scale).
